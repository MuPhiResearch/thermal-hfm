Thermal HFM Module
==================

A solver extension for the `MATLAB Reservoir Simulation Toolbox (MRST) 2026a
<https://www.sintef.no/projectweb/mrst/>`_ that couples the ``geothermal`` and
``hfm/shale`` modules to simulate thermal transport in fractured reservoirs
using the Embedded Discrete Fracture Model (EDFM) and its projection-based
extension (pEDFM).
